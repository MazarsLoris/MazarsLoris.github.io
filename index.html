À propos de moi

Issu d'une formation en Mathématiques, j'ai transféré ma rigueur logique vers la Data Analyse.

Mon approche dépasse la simple technique : je construis des pipelines de données réalistes pour transformer des données brutes (et souvent complexes) en décisions stratégiques pour les managers.

Ma stack technique : Python & SQL pour la fiabilisation, Power BI pour le pilotage, et R pour la statistique avancée.
